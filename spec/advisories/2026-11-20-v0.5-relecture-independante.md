# Advisory 2026-11-20 (2) — First independent review of AgentBudget v0.5

*English below · [Résumé en français](#résumé-en-français)*

| | |
|---|---|
| Affected | AgentBudget **v0.5** contract and the `vault-cli` owner tool (survival mode, freeze); testnet-10 only |
| Fixed in | **v0.5.1** (contract hash in `contracts/EMPREINTES.txt`) and the matching tool |
| Found by | an independent reviewer who had not seen the work, asked to break it |
| Loss bound | **not affected**: the reviewer found no transaction exceeding `capacity + capacity × D / refillPeriod` |

## Findings and fixes

| # | Severity | Finding | Fix |
|---|---|---|---|
| 1 | High | **Survival-mode decoy.** An agent could pay a decoy output carrying exactly the vault's continuation script. `retrouver` followed it, the owner froze the decoy and believed the vault closed while the real vault kept paying. | The output found must carry the vault's **lineage** (covenant id assigned by the network, checked against the node); test `leurre_au_meme_script_ignore` |
| 2 | High | **Lying indexer.** The tool claimed a lying indexer could not lead to a fake vault; it could (invented hop plus a real dust output). | Same lineage check: an invented output has no lineage |
| 3 | Medium | **Freeze could be delayed.** An agent could keep a payment pending, or out-bid the freeze (agent fee cap 3 M sompi, freeze fee 1.5 M). | Freeze fee ≥ 2 × `maxFee`, escalating; replaces a pending agent payment; relocates the vault and retries |
| 4 | Medium | **Parameter guards.** v0.5 claimed aberrant parameters endangered no funds; false for a **negative refill period** (full reserve at every payment). Arithmetic overflow is undefined behaviour in SilverScript. | **Contract v0.5.1**: guards in the script (`refillPeriod > 0`, `capacity > 0`, `maxPerPayment ≤ capacity`, `0 ≤ tokens ≤ capacity`, `maxFee ≥ 0`, `capacity × refillPeriod` within 63 bits, checked by division) |
| 5 | Medium-low | A malicious vendor could leave the local state stale and stall the router. | A stale state triggers `retrouver` from the origin |
| 6 | Low | `verify-proof.sh` printed PASS for a test that does not exist. | Each step now requires "1 passed" |
| 7–8 | Low / notes | Missing test cases; indexer pagination; Argon2 parameter caps; one rare IPv6 form; URL query strings in logs; stale v0.4 references. | All addressed |

Reproduce: `./verify-proof.sh`. Status: proven on paper, verified by automated tests, **not
audited**. A second review pass on these fixes is pending.

## Résumé en français

Un relecteur indépendant, chargé de casser le travail, n'a trouvé **aucune transaction qui dépasse
la borne de perte**. Il a trouvé deux problèmes élevés dans le mode survie (un leurre au même
script, un indexeur menteur), corrigés en exigeant la **lignée** du coffre vérifiée auprès du
nœud ; un gel qui pouvait être retardé (désormais prioritaire, avec remplacement) ; et une garde
manquante pour une période de recharge négative, désormais **dans le contrat (v0.5.1)**, avec
toutes les autres gardes de paramètres. Seconde relecture des corrections à venir.
